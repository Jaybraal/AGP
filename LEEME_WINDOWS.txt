=====================================================
  SISTEMA DE GESTION DE PRESTAMOS - AGP
  Instrucciones para Windows
=====================================================

INSTALACION (solo la primera vez)
-----------------------------------

1. Haz doble clic en:  AGP-Installer.exe
2. Sigue los pasos del asistente (siguiente, siguiente...)
3. Al terminar, haz clic en "Iniciar AGP Sistema de Prestamos"

Listo. El sistema queda instalado con un icono en el Escritorio.

USO DIARIO
----------
Haz doble clic en el icono del Escritorio:
  "AGP Sistema de Prestamos"

LA BASE DE DATOS
----------------
Todos los datos se guardan en:
  C:\Users\TuNombre\AppData\Local\AGP\data\prestamos.db
  (o dentro de la carpeta donde instalaste el programa)

- Hazle una copia de seguridad periodicamente
- Si cambias de computadora, copia ese archivo a la nueva maquina

DESINSTALAR
-----------
Panel de Control -> Programas -> AGP Sistema de Prestamos -> Desinstalar
(o desde el menu Inicio -> AGP -> Desinstalar)

SOPORTE
-------
Si el sistema no abre, contacta al administrador del sistema.
